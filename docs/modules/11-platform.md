## الفكرة

**دورة حياة الصيدلية بالمنصة:**

```
طلب انضمام ← قبول وتفعيل ← تجربة 30 يوم ← دفع وتأكيد ← اشتراك ← تجديد … أو إيقاف
```

**صاحبة المنصة بتشوف الاستخدام، مش الأسرار.** بتعرف كم صنف وكم موظف وكم فاتورة اليوم، عشان تعرف إذا الصيدلية مستفيدة. بس كم باعت وكم ربحت ومين زبائنها، هاد للصيدلية بس.

**الدفع يدوي:** بغزة ما في بوابات دفع إلكتروني بتشتغل منيح. فالصيدلية بتحول على البنك أو جوال باي، وبتبعت صورة الإيصال، وصاحبة المنصة بتتأكد وبتفعّل.

## الشاشات

### 1. الصيدليات

- **أربع أرقام:** صيدليات مشتركة، بالتجربة، اشتراكها بيخلص هالأسبوع (برتقالي)، موقوفة (أحمر).
- **فلاتر:** الكل، تجربة، مشتركة، موقوفة (مع عدد كل واحد). والمدينة. وبحث بالاسم أو المالك أو الجوال.
- **الجدول:** الصيدلية (رابط)، المالك وجواله، المدينة، الباقة بلون، ينتهي ("بعد 3 أيام" بالبرتقالي لو أسبوع أو أقل)، الأصناف، الموظفون، آخر نشاط ("من 10 دقايق").
- **الترتيب:** اللي بيخلص أول فوق، لأنه هاد اللي لازم تتابعيه.

### 2. تفاصيل صيدلية

- فوق: الاسم والباقة، وكم باقي، وزرين: "ابعتي رسالة واتساب" و"تفعيل اشتراك".
- **البيانات:** المالك، الجوال، المدينة والحي، الترخيص، تاريخ التسجيل.
- **الاستخدام:** الأصناف، الموظفون (وكم نشط)، فواتير اليوم، آخر دخول، وقائمة البداية خلصت ولا لأ. وتحتها: "أعداد بس. مبالغ المبيعات والأرباح خاصة بالصيدلية".
- **إجراءات:**

| الإجراء              | شو بيعمل                                                        |
| -------------------- | --------------------------------------------------------------- |
| تمديد التجربة        | 7 أو 14 يوم. بس للي بالتجربة                                    |
| تغيير الباقة         | أساسية، احترافية، أو سنوية، وكم شهر. لدفعة انعملت برا التطبيق   |
| دخول للدعم الفني     | بيطلب إذن المالك. لحد ما يوافق، الزر بيصير "بانتظار إذن المالك" |
| إيقاف الصيدلية       | بسبب إجباري. بتصير للقراءة بس، وما بينمسح شي                    |
| إعادة تشغيل الصيدلية | للموقوفة                                                        |

- **سجل الاشتراك:** كل شي صار بتاريخه: الانضمام، بداية التجربة، التمديد، الدفعات، الإيقاف. وآخر سطر: متى بتخلص الباقة الحالية.

### 3. الاشتراكات والمدفوعات

- **الباقات:** أساسية (شهري)، احترافية (شهري)، سنوية. كل وحدة: كم صيدلية عليها، خانة السعر وزر حفظ، والمميزات. ولو في باقة بلا سعر: "الأسعار لسا ما تحددت".
- **المدفوعات:** التاريخ، الصيدلية، الباقة، المبلغ، طريقة الدفع، صورة الإيصال، الحالة. وفوق: "2 بانتظار التأكيد".
- **للي بانتظار:** "تأكيد وتفعيل" (الباقة بتشتغل فوراً) أو "رفض" (بسبب بيوصل للصيدلية).

## قرارات مهمة

1. **أعداد، مش مبالغ:** ثقة الصيدليات بالمنصة أهم من أي رقم. لو صاحبة المنصة بتشوف أرباح الكل، ما حدا رح يشترك.
2. **الإيقاف ما بيمسح:** الصيدلية ممكن ترجع تدفع. بياناتها بتضل، بس للقراءة.
3. **الدعم بإذن:** حتى صاحبة المنصة ما بتدخل صيدلية بدون موافقة، وكل شي بينكتب.
4. **التجديد بيكمل:** لو دفعت قبل ما يخلص اشتراكها، الشهر الجديد بيبلش من آخر الاشتراك، مش من اليوم. ما بتخسر أيام.
5. **السبب إجباري:** بالإيقاف والرفض، لأنه بيوصل للصيدلية، و"انرفض" بلا سبب بيزعل.
6. **الأيام بالتاريخ الحقيقي:** زي سطر الأيام الباقية بالصيدلية، عشان الرقمين يطابقوا.

## السيرفر الوهمي

```
src/app/mocks/platform-data.ts       7 صيدليات، 5 دفعات، وأسعار فاضية
src/app/mocks/handlers/platform.ts   الروابط
```

- **صيدلية الشفاء** (رقم 1) هي صيدليتنا: أصنافها وموظفيها وفواتيرها بتنقرا من بيانات التطبيق نفسها. ضيفي صنف، وبيزيد العدد هون.
- باقي الصيدليات أرقامها ثابتة، وآخر نشاطها محسوب من الساعة الحقيقية.
- صور الإيصالات صور صغيرة مولّدة، بس عشان الرابط يفتح.

| ----------------------------------------------------------------------------- | ------------------ |

**قواعد مهمة للباك إند:**

- كله لـ `platform_owner` بس.

- الصيدلية الموقوفة: كل طلب تعديل منها بيرجع 403، والقراءة مسموحة.
- صور الإيصالات بروابط موقّعة ومؤقتة.

## شو تعلمنا

1. **المنصة بتبيع ثقة:** الخصوصية مش ميزة إضافية. هي سبب إنه الصيدلية تشترك.
2. **الإيقاف عكس الحذف:** اللي بيوقف ممكن يرجع. خلّي طريق الرجوع سهل.
3. **التنظيم بيكبر مع المشروع:** لما الكيانات صارت كتير، جمعناها. نفس اللي عملناه بالصفحات بالوحدة 3.
4. **آخر شاشة بتشيل السقالة:** صفحة "قريباً" ساعدتنا طول الطريق. لما خلصنا، شلناها.

**بعد هالوحدة:** ملف التعريف الشامل للمشروع.
