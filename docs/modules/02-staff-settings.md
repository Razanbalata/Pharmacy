## الفكرة

الصيدلية فيها تلات أدوار:

| الدور   | شو بيعمل                                                     |
| ------- | ------------------------------------------------------------ |
| المديرة | المالكة. بتشوف كل شي، وهي الوحيدة اللي بتفتح هالتلات شاشات   |
| الصيدلي | بيبيع، وبيستلم البضاعة، وبيجرد، وممكن يوافق على فروقات الجرد |
| الكاشير | بيبيع بس                                                     |

وفوق الدور، كل موظف إله:

- حد خصم بالنسبة المئوية، ما بيقدر يتعداه وهو بيبيع.
- تلات صلاحيات إضافية: البيع بالدين، وشوفة سعر الشراء، والموافقة على الجرد (للصيدلي بس).

**الرحلة:**

```
المديرة بتضيف موظف  →  النظام بيعطيها كلمة مرور مؤقتة
     →  بتبعتها على واتساب بضغطة  →  الموظف بيدخل وبيغيرها
```

## الشاشات

### 1. الموظفون

**متى:** لما يجي موظف جديد، أو يتغير دوره، أو يترك الشغل، أو ينسى كلمة المرور.

**فيها:**

- جدول: الاسم والجوال، الدور، حد الخصم، آخر دخول، والحالة.
- مفتاح الحالة بكل سطر. الإيقاف بيسأل أول، وبعده رسالة فيها زر "تراجع".
- زر "كلمة مرور جديدة" لكل موظف.
- تلات بطاقات تحت بتشرح كل دور شو بيقدر يعمل.
- ملاحظة: الموظف ما بينحذف، بينوقف بس.

**نافذة الإضافة والتعديل** (بتنفتح من جهة البداية):

- الاسم، الجوال، والإيميل اختياري.
- الدور: صيدلي أو كاشير. لما تختاري كاشير، صلاحية الموافقة على الجرد بتتعطل.
- حد الخصم من 0 لـ 100.
- الصلاحيات التلاتة كمفاتيح.

بعد الإضافة بتطلع نافذة كلمة المرور المؤقتة: زر نسخ، وزر واتساب بيفتح محادثة مع الموظف والرسالة جاهزة.

**المالكة** بتطلع أول سطر وما إلها مفتاح ولا زر تعديل. ما حدا بيقدر يوقفها.

### 2. سجل النشاط

**متى:** لما المديرة بدها تعرف مين عطى هالخصم، أو مين غير الإعدادات، أو شو صار بالوردية المسائية.

**فيها:**

- الفترة: اليوم، الأسبوع، الشهر.
- اختيار الموظف، واختيار النوع.
- مربع "الحساسة بس": الخصومات الكبيرة والمرتجعات والتالف والتعديل الجماعي.
- بحث برقم فاتورة أو اسم.
- كل سطر جملة كاملة: مين، شو عمل، الساعة، وسطر تفاصيل تحته. والحساسة إلها شارة.

**السجل للقراءة بس.** ولا حد بيقدر يعدله أو يمسحه، ولا المديرة نفسها. هيك بيضل موثوق.

### 3. الإعدادات

**متى:** أول ما الصيدلية تبلش، وبعدين كل ما بدها تغير طريقة شغل.

صفحة وحدة طويلة، وعلى جهة البداية قائمة بتنقلك لأي قسم:

| القسم              | شو فيه                                                                                    |
| ------------------ | ----------------------------------------------------------------------------------------- |
| الصيدلية           | الاسم، الترخيص، المدينة، الجوال، العنوان                                                  |
| البيع والدفع       | طرق الدفع، حد الدين الافتراضي، مدة المرتجع، الورديات، البيع بالحبة، البيع لما المخزون صفر |
| المخزون والتنبيهات | التنبيه قبل الانتهاء، حد النقص الافتراضي، ملخص التنبيهات اليومي على واتساب                |
| الطباعة            | مقاس الإيصال، الطباعة التلقائية، رسالة آخر الإيصال، مقاس ملصق الباركود                    |
| الاشتراك           | الخطة الحالية والأيام الباقية، والخطط التلاتة (الأسعار لسا مكتوب مكانها السعر)            |
| النسخة الاحتياطية  | آخر نسخة تلقائية، وزر تنزيل كل البيانات                                                   |
| اللغة والمظهر      | لكل مستخدم لحاله، وبيتغير فوراً بدون حفظ                                                   |

**الحفظ:** زر الحفظ معطل لحد ما تغيري إشي. أول ما تغيري، بيطلع شريط تحت فيه "في تعديلات ما انحفظت". والقيم اللي برا الحدود (مثلاً مدة مرتجع سالبة) بتطلع غلط تحت حقلها.

**"البيع من الدفعة الأقرب انتهاء"** مكتوب جنبه "مفعل دايماً" ومش مفتاح. هاد قرار: الصيدلية ما لازم تبيع الدواء الجديد وتترك القديم ينتهي.

## الصلاحيات: مين بيفتح شو

القرار كله بمكان واحد:

```
src/entities/session/model/permissions.ts
```

الدالة اسمها:

```
canAccess(role, area)
```

والمناطق الجديدة بهالوحدة: الموظفين، والسجل، والإعدادات. التلاتة للمديرة بس.

**مين بيستخدم هالدالة:**

- القائمة الجانبية: ما بتعرض الرابط للي ما إله صلاحية.
- البحث الشامل: ما بيقترح الشاشة.
- الحارس الجديد اسمه:

```
AreaGuard
```

هو بيلف كل صفحة إلها صلاحية بملف التوجيه. لو حد كتب الرابط بإيده، بيشوف رسالة "هاي الشاشة مش من صلاحياتك" ومعها رجوع.

**مهم:** هاد كله للواجهة بس. السيرفر لازم يرفض كمان، لأنه أي حد بيقدر يبعت طلب مباشرة.

```

```

## قرارات مهمة

1. **الموظف ما بينحذف:** فواتيره وسجله لازم يضلوا بأسمه. بدل الحذف في إيقاف، والموقوف ما بيقدر يدخل.
2. **كلمة المرور المؤقتة بتطلع مرة وحدة:** ما بنخزنها بالواجهة، ولو ضاعت بنعمل وحدة جديدة.
3. **السجل بيوصل كرمز مش كجملة:** السيرفر بيبعت مثلاً "خصم" ومعه "15%" ورقم الفاتورة، والواجهة بتركب الجملة باللغة المختارة. هيك نفس السطر بينقرأ صح بالعربي والإنجليزي.
4. **التراجع بدل السؤال المزعج:** الإيقاف بيسأل مرة، وبعدها في زر تراجع لو الضغطة كانت غلط.
5. **الإعدادات كلها بصفحة وحدة:** مش تبويبات. المديرة بتمرر وبتشوف كل شي، والقائمة الجانبية للقفز السريع.

## شو تعلمنا

1. **الصلاحية بمكان واحد:** القائمة والبحث والحارس كلهم بيسألوا نفس الدالة. لو تغير دور، بنغير سطر واحد.
2. **الواجهة بتخفي، السيرفر بيمنع:** إخفاء الشاشة راحة للمستخدم، مش حماية.
3. **ما بنمسح التاريخ:** الإيقاف بدل الحذف، والسجل للقراءة بس.
4. **النص بيتركب بالواجهة:** السيرفر بيبعت معلومات، والواجهة بتحولها لجملة باللغة الصح.
5. **قواعد الهيكلية بتعلم:** كل رفض من أداة الفحص كان سؤال "وين مكان هاد صح؟"، والجواب دايماً كان أوضح من الأول.

**الوحدة الجاية:** الأصناف والتصنيفات والمواد الفعالة.
