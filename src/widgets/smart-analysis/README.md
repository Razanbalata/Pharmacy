# smart-analysis

التحليل الذكي للشهر: حالة عامة، ونقاط قليلة لكل وحدة زر، وملخص.

بيفتح كلوحة جانبية فوق الصفحة الحالية، فالمستخدم بيضله مكانه. بنستخدمه من لوحة التحكم ومن التقارير ومن صفحة المساعد.

- `SmartAnalysisButton`: زر بيفتح اللوحة مكانه.
- `AnalysisDrawer`: اللوحة نفسها، لما الصفحة بدها تتحكم بفتحها.
- `useActionLink`: وين بيودي كل زر تحت الجواب، وشو مكتوب عليه.
