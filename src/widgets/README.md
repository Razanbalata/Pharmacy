# طبقة القطع الكبيرة

قطع واجهة كبيرة بتتكرر بأكتر من صفحة، وبتجمع أكتر من ميزة.

| القطعة            | شو بتعمل                                       |
| ----------------- | ---------------------------------------------- |
| `network-status/` | شريط "الاتصال مقطوع" وعدد العمليات اللي بتستنى |

القطع الجاية حسب التصميم:

- القائمة الجانبية، وبتتغير حسب دور المستخدم
- الشريط العلوي، وفيه البحث والجرس وزر البيع الجديد
- البحث الشامل
- سلة نقطة البيع
