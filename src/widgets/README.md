# طبقة القطع الكبيرة

قطع واجهة كبيرة بتتكرر بأكتر من صفحة، وبتجمع أكتر من ميزة.

| القطعة             | شو بتعمل                                                                                                    |
| ------------------ | ----------------------------------------------------------------------------------------------------------- |
| `sidebar/`         | القائمة الجانبية: مجموعاتها، والعنصر المحدد، وعدد التنبيهات، وأيام التجربة. بتخفي اللي الدور مش مسموحله فيه |
| `topbar/`          | الشريط العلوي: البحث، وزر البيع الجديد، والجرس، وقائمة المستخدم فيها اللغة والمظهر                          |
| `command-palette/` | البحث الشامل: بيفتح من أي مكان بـ Ctrl K، وبيلاقي الشاشات والأوامر بالعربي والإنجليزي                       |
| `network-status/`  | شريط "الاتصال مقطوع" وعدد العمليات اللي بتستنى                                                              |

القطع الجاية حسب التصميم: سلة نقطة البيع، والبطاقات الرقمية بلوحة التحكم، وغيرهم مع وحداتهم.

## قاعدة مهمة

قطعة ما بتستورد قطعة تانية. مثلاً الشريط العلوي فيه زر البحث، بس ما بيعرف شي عن البحث الشامل. بياخد دالة اسمها `onOpenSearch`، والإطار بطبقة التطبيق هو اللي بيربطهم:

```
src/app/routes/AppLayout.tsx
```
