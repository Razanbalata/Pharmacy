# طبقة الصفحات

كل مجلد هون صفحة كاملة إلها رابط. الصفحة بتركّب القطع من الطبقات اللي تحتها، وما بتحتوي منطق معقد.

| الصفحة                           | الرابط                                 | شو هي                                                        |
| -------------------------------- | -------------------------------------- | ------------------------------------------------------------ |
| `auth/login/`                    | `/login`                               | تسجيل الدخول. كل دور بيروح لشاشته الأولى                     |
| `auth/join/`                     | `/join`                                | طلب الانضمام للصيدليات الجديدة                               |
| `auth/activate/`                 | `/activate/:token`                     | تفعيل الحساب من رابط الواتساب واختيار كلمة المرور            |
| `auth/forgot-password/`          | `/forgot-password`                     | استرجاع كلمة المرور بتلات خطوات                              |
| `setup/`                         | `/setup`                               | تجهيز الصيدلية بعد التفعيل وطريقة البداية                    |
| `getting-started/`               | `/getting-started`                     | قائمة البداية: ست خطوات لحد ما الصيدلية تشتغل                |
| `platform-requests/`             | `/platform/requests`                   | طلبات الانضمام بلوحة صاحبة المنصة                            |
| `staff/`                         | `/staff`                               | الموظفين: القائمة، والإضافة والتعديل، والإيقاف               |
| `activity/`                      | `/staff/activity`                      | سجل النشاط: مين عمل شو ومتى، مع الفلاتر                      |
| `settings/`                      | `/settings`                            | إعدادات الصيدلية كلها بصفحة وحدة                             |
| `catalog/products/`              | `/products`                            | قائمة الأصناف: التبويبات حسب الحالة، الفلاتر، البحث، التحديد |
| `catalog/product-detail/`        | `/products/:id`                        | تفاصيل الصنف: الدفعات، المبيعات، الحركات، البدائل            |
| `catalog/product-form/`          | `/products/new` و `/products/:id/edit` | إضافة صنف أو تعديله بنفس النموذج                             |
| `catalog/categories/`            | `/categories`                          | التصنيفات: إضافة بسطر، تعديل بمكانه، دمج، حذف الفاضي         |
| `catalog/ingredients/`           | `/ingredients`                         | المواد الفعالة وأصناف كل مادة، ودمج الأسماء المكررة          |
| `catalog/product-labels/`        | `/products/labels`                     | ملصقات الباركود: عدد النسخ، المقاس، المعاينة والطباعة        |
| `catalog/product-import/`        | `/products/import`                     | معالج الاستيراد من إكسل بأربع خطوات                          |
| `purchasing/suppliers/`          | `/suppliers`                           | الموردين ومجموع المستحق، والدفع والطلب من كل سطر             |
| `purchasing/supplier-statement/` | `/suppliers/:id`                       | كشف حساب المورد بفترة، والدفعات                              |
| `purchasing/purchases/`          | `/purchases`                           | طلبات الشراء بفلاترها، والطلبيات المقترحة للنواقص            |
| `purchasing/purchase-order/`     | `/purchases/new` و `/purchases/:id`    | طلب جديد أو مسودة للتعديل، أو عرض طلب انبعت                  |
| `purchasing/purchase-receive/`   | `/purchases/:id/receive`               | استلام البضاعة: الكميات والدفعات والتواريخ والدفع            |
| `stock/movements/`               | `/stock/movements`                     | سجل كل حركات المخزون بفلاتره ومجاميعه                        |
| `stock/damage/`                  | `/stock/damage`                        | التالف: خسارة الشهر، المنتهي بالمخزون، التسجيل، والسجل       |
| `coming-soon/`                   | كل شاشة لسا ما انبنت                   | صفحة مؤقتة بتقول بأي وحدة رح تنبنى الشاشة                    |
| `ui-kit/`                        | `/ui-kit`                              | مكتبة المكونات                                               |
| `not-found/`                     | أي رابط مش موجود                       | صفحة مش موجودة                                               |

## المجموعات

لما زادت الصفحات عن 20، جمعناها بمجلدات حسب الموضوع، عشان ما تضيع:

| المجموعة      | شو فيها                                     |
| ------------- | ------------------------------------------- |
| `auth/`       | الدخول، الانضمام، التفعيل، نسيت كلمة المرور |
| `catalog/`    | الأصناف والتصنيفات والمواد الفعالة          |
| `stock/`      | الجرد والتالف وسجل الحركات                  |
| `purchasing/` | الموردين وطلبات الشراء والاستلام            |

المجموعة مجرد مجلد. كل صفحة جواها لسا مستقلة وإلها ملفها الرئيسي.

كل صفحة جديدة بتنضاف لهالجدول ولملف التوجيه، وبتاخد مكان صفحتها المؤقتة.

## العناوين

كل عناوين التطبيق مكتوبة بمكان واحد:

```
src/shared/config/routes.ts
```

الروابط والقائمة الجانبية والبحث الشامل كلهم بيقرأوا من هون. لو بدك تغيري عنوان، بتغيريه هون وبس.

## التحميل

ولا صفحة بتعرض دوامة تحميل. لما تنفتح صفحة، بيطلع مكانها هيكل رمادي بنفس شكلها: قائمة، أو لوحة تحكم، أو تفاصيل، أو نموذج. أي شكل لأي صفحة محدد هون:

```
src/app/routes/skeletons.ts
```
