# طبقة الصفحات

كل مجلد هون صفحة كاملة إلها رابط. الصفحة بتركّب القطع من الطبقات اللي تحتها، وما بتحتوي منطق معقد.

| الصفحة               | الرابط                                 | شو هي                                                        |
| -------------------- | -------------------------------------- | ------------------------------------------------------------ |
| `login/`             | `/login`                               | تسجيل الدخول. كل دور بيروح لشاشته الأولى                     |
| `join/`              | `/join`                                | طلب الانضمام للصيدليات الجديدة                               |
| `activate/`          | `/activate/:token`                     | تفعيل الحساب من رابط الواتساب واختيار كلمة المرور            |
| `forgot-password/`   | `/forgot-password`                     | استرجاع كلمة المرور بتلات خطوات                              |
| `setup/`             | `/setup`                               | تجهيز الصيدلية بعد التفعيل وطريقة البداية                    |
| `getting-started/`   | `/getting-started`                     | قائمة البداية: ست خطوات لحد ما الصيدلية تشتغل                |
| `platform-requests/` | `/platform/requests`                   | طلبات الانضمام بلوحة صاحبة المنصة                            |
| `staff/`             | `/staff`                               | الموظفين: القائمة، والإضافة والتعديل، والإيقاف               |
| `activity/`          | `/staff/activity`                      | سجل النشاط: مين عمل شو ومتى، مع الفلاتر                      |
| `settings/`          | `/settings`                            | إعدادات الصيدلية كلها بصفحة وحدة                             |
| `products/`          | `/products`                            | قائمة الأصناف: التبويبات حسب الحالة، الفلاتر، البحث، التحديد |
| `product-detail/`    | `/products/:id`                        | تفاصيل الصنف: الدفعات، المبيعات، الحركات، البدائل            |
| `product-form/`      | `/products/new` و `/products/:id/edit` | إضافة صنف أو تعديله بنفس النموذج                             |
| `categories/`        | `/categories`                          | التصنيفات: إضافة بسطر، تعديل بمكانه، دمج، حذف الفاضي         |
| `ingredients/`       | `/ingredients`                         | المواد الفعالة وأصناف كل مادة، ودمج الأسماء المكررة          |
| `product-labels/`    | `/products/labels`                     | ملصقات الباركود: عدد النسخ، المقاس، المعاينة والطباعة        |
| `coming-soon/`       | كل شاشة لسا ما انبنت                   | صفحة مؤقتة بتقول بأي وحدة رح تنبنى الشاشة                    |
| `ui-kit/`            | `/ui-kit`                              | مكتبة المكونات                                               |
| `not-found/`         | أي رابط مش موجود                       | صفحة مش موجودة                                               |

كل صفحة جديدة بتنضاف لهالجدول ولملف التوجيه، وبتاخد مكان صفحتها المؤقتة.

## العناوين

كل عناوين التطبيق مكتوبة بمكان واحد:

```
src/shared/config/routes.ts
```

الروابط والقائمة الجانبية والبحث الشامل كلهم بيقرأوا من هون. لو بدك تغيري عنوان، بتغيريه هون وبس.

## التحميل

ولا صفحة بتعرض دوامة تحميل. لما تنفتح صفحة، بيطلع مكانها هيكل رمادي بنفس شكلها: قائمة، أو لوحة تحكم، أو تفاصيل، أو نموذج. أي شكل لأي صفحة محدد هون:

```
src/app/routes/skeletons.ts
```
