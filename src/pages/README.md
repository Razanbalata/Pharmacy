# طبقة الصفحات

كل مجلد هون صفحة كاملة إلها رابط. الصفحة بتركّب القطع من الطبقات اللي تحتها، وما بتحتوي منطق معقد.

| الصفحة       | الرابط           | الشاشة بالتصميم                                 |
| ------------ | ---------------- | ----------------------------------------------- |
| `home/`      | `/`              | صفحة مؤقتة لعرض نظام التصميم                    |
| `ui-kit/`    | `/ui-kit`        | مكتبة المكونات: كل المكونات المشتركة بمكان واحد |
| `not-found/` | أي رابط مش موجود | صفحة مش موجودة                                  |

كل صفحة جديدة بتنضاف لهالجدول ولملف التوجيه.
