# ميزة: تبديل المظهر

بتخلي المستخدم يختار: حسب الجهاز، نهاري، أو ليلي. الاختيار بينحفظ بالمتصفح.

| الملف                  | شو فيه                            |
| ---------------------- | --------------------------------- |
| `ui/ThemeSwitcher.tsx` | الأزرار التلاتة                   |
| `index.ts`             | الشي الوحيد اللي بيطلع برا الميزة |

المنطق نفسه (حفظ الاختيار وتطبيقه على الصفحة) موجود بالطبقة المشتركة، لأنه التطبيق كله محتاجه:

```
src/shared/lib/theme/
```

والتطبيق الفعلي على الصفحة بيصير بـ:

```
src/app/theme/ThemeProvider.tsx
```
