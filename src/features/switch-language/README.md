# ميزة: تبديل اللغة

بتبدل بين العربي والإنجليزي. مع اللغة بيتبدل اتجاه الصفحة كمان: العربي من اليمين، والإنجليزي من الشمال. الاختيار بينحفظ بالمتصفح.

| الملف                     | شو فيه                            |
| ------------------------- | --------------------------------- |
| `ui/LanguageSwitcher.tsx` | زرين اللغة                        |
| `index.ts`                | الشي الوحيد اللي بيطلع برا الميزة |

النصوص نفسها موجودة هون:

```
src/shared/i18n/locales/ar.ts
src/shared/i18n/locales/en.ts
```

أي نص جديد بينكتب بالعربي أول، والإنجليزي لازم يكون إله نفس المفاتيح بالضبط، وإلا فحص الأنواع بيفشل.
