# طبقة الميزات

كل ميزة هي فعل بيعمله المستخدم وإله قيمة لحاله.

| الميزة                          | شو بتعمل                                                                  |
| ------------------------------- | ------------------------------------------------------------------------- |
| `auth/login/`                   | نموذج الدخول، وعدد المحاولات الباقية، والقفل بعد محاولات كتير             |
| `auth/logout/`                  | زر الخروج، وبيمسح كل البيانات المحفوظة بالمتصفح                           |
| `auth/reset-password/`          | استرجاع كلمة المرور: الجوال، الكود، الكلمة الجديدة                        |
| `join/submit-request/`          | نموذج طلب الانضمام وبطاقة "وصلنا طلبك"                                    |
| `join/activate-account/`        | اختيار كلمة المرور من رابط التفعيل                                        |
| `pharmacy/setup-pharmacy/`      | بيانات الصيدلية وطريقة البداية                                            |
| `pharmacy/dismiss-onboarding/`  | زر "خفي القائمة"                                                          |
| `platform/review-join-request/` | قبول الطلب أو رفضه، وإضافة صيدلية باليد                                   |
| `staff/manage/`                 | نافذة إضافة موظف أو تعديله، والصلاحيات وحد الخصم                          |
| `staff/toggle-status/`          | مفتاح إيقاف الموظف وتشغيله، مع تأكيد وزر تراجع                            |
| `staff/reset-password/`         | كلمة مرور مؤقتة جديدة للموظف تنبعتله على واتساب                           |
| `product/edit-product/`         | نموذج الصنف: البحث بالقائمة المشتركة، الوحدات والأسعار، المخزون الافتتاحي |
| `product/bulk-edit/`            | تعديل عدة أصناف مع بعض، مع معاينة قبل وبعد                                |
| `product/import-products/`      | معالج الاستيراد: قراءة الملف، ربط الأعمدة، التصحيح، التراجع               |
| `category/manage/`              | إضافة تصنيف وتعديل اسمه ودمجه وحذف الفاضي                                 |
| `ingredient/manage/`            | إضافة مادة فعالة وتعديل اسمها ودمجها مع مادة تانية                        |
| `customer/manage/`              | إضافة زبون وتعديله. الكاشير بالاسم والهاتف بس                             |
| `customer/record-payment/`      | تسديد دين زبون وسند القبض                                                 |
| `expense/record-expense/`       | سطر إضافة مصروف: النوع والمبلغ ومن وين                                    |
| `supplier/manage/`              | إضافة مورد وتعديل بياناته                                                 |
| `supplier/record-payment/`      | تسجيل دفعة لمورد: المبلغ والطريقة والفاتورة                               |
| `purchase/edit-order/`          | نموذج طلب الشراء: المورد والأصناف والكميات، والإرسال واتساب               |
| `purchase/suggested-orders/`    | تجهيز مسودات من الأصناف الناقصة، طلبية لكل مورد                           |
| `purchase/receive-order/`       | الاستلام: الواصل والدفعة والانتهاء لكل صنف، والدفع للمورد                 |
| `purchase/cancel-order/`        | إلغاء طلب ما وصل منه شي                                                   |
| `stock-count/start-count/`      | بدء جرد لتصنيف أو للصيدلية كلها                                           |
| `stock-count/conduct-count/`    | ورقة الجرد: العدد والفرق والسبب، الحفظ والاعتماد                          |
| `damage/record-damage/`         | تسجيل تالف لدفعة: الكمية والسبب والخسارة                                  |
| `damage/write-off-expired/`     | تسجيل كل الدفعات المنتهية تالف مرة وحدة                                   |
| `sale/find-product/`            | بحث الصنف بالاسم والمادة والباركود، والبدائل للنافد                       |
| `sale/edit-cart/`               | الفاتورة الحالية: الزبون والوحدات والكميات والمجاميع                      |
| `sale/checkout/`                | نافذة الدفع بأنواعه، والإيصال                                             |
| `sale/discount/`                | الخصم ضمن حد البائع                                                       |
| `sale/held-sales/`              | تعليق الفاتورة واستئنافها وإلغاؤها                                        |
| `sale-return/create-return/`    | نموذج المرتجع: الكميات والسبب والاسترداد وموافقة الصيدلي                  |
| `shift/open-shift/`             | فتح وردية: عدّ النقد بالدرج                                                |
| `shift/close-shift/`            | إغلاق الوردية: النقد المتوقع والفعلي والفرق                               |
| `settings/edit-settings/`       | نموذج الإعدادات كامل، وشريط "في تعديلات ما انحفظت"                        |
| `switch-theme/`                 | تبديل المظهر: حسب الجهاز، نهاري، ليلي                                     |
| `switch-language/`              | تبديل اللغة، ومعها اتجاه الصفحة                                           |

الميزات مجمعة بمجلدات حسب الموضوع: الدخول، الانضمام، الصيدلية، المنصة، الموظفين، الإعدادات. المجلد اللي بيجمع ما بيكون إله ملف رئيسي، كل ميزة جواه إلها ملفها.

النماذج كلها بنفس الطريقة:

- الأداة: React Hook Form
- قواعد الحقول مكتوبة بـ Zod، ورسالة الخطأ هي مفتاح ترجمة مثل `validation.required`
- أخطاء السيرفر بتنحط تحت حقلها عن طريق `applyServerErrors`

قاعدة: ميزة ما بتستورد من ميزة تانية. لو احتاجوا بعض، الصفحة أو القطعة الكبيرة بتجمعهم.
