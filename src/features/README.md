# طبقة الميزات

كل ميزة هي فعل بيعمله المستخدم وإله قيمة لحاله.

| الميزة             | شو بتعمل                                              |
| ------------------ | ----------------------------------------------------- |
| `switch-theme/`    | تبديل المظهر: حسب الجهاز، نهاري، ليلي                 |
| `switch-language/` | تبديل اللغة بين العربي والإنجليزي، ومعها اتجاه الصفحة |

الميزات الجاية: تسجيل الدخول، طلب الانضمام، إضافة صنف للفاتورة، الدفع، المرتجع، وغيرهم.

قاعدة: ميزة ما بتستورد من ميزة تانية. لو احتاجوا بعض، الصفحة أو القطعة الكبيرة بتجمعهم.
