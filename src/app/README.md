# طبقة التطبيق

هون التطبيق بيشتغل: كل شي بيلف كل الصفحات.

| المكان    | شو فيه                                                                     |
| --------- | -------------------------------------------------------------------------- |
| `App.tsx` | نقطة البداية، بتجمع كل شي                                                  |
| `theme/`  | بيطبق المظهر المختار على الصفحة                                            |
| `i18n/`   | بيطبق اللغة والاتجاه على الصفحة                                            |
| `query/`  | إعداد جلب البيانات من السيرفر                                              |
| `routes/` | كل الروابط، وإطار التطبيق (القائمة والشريط والبحث)، وهيكل التحميل لكل صفحة |
| `mocks/`  | السيرفر الوهمي للتطوير والاختبارات                                         |
| `styles/` | الأنماط العامة وألوان نظام التصميم                                         |

ما في كود صيدلية هون. لو لقيتي حالك بتكتبي منطق بيع أو مخزون بهالطبقة، مكانه غلط.

أسماء المجلدات هون بتوصف الغرض (مظهر، لغة، روابط)، مش نوع الملف. هاي قاعدة من قواعد الهيكلية.

## الإطار

```
RootLayout        ← كل الصفحات: شريط انقطاع النت والرسائل السريعة
  AppLayout       ← موظفين الصيدلية: القائمة الجانبية والشريط العلوي والبحث
  PlatformLayout  ← صاحبة المنصة بس، وبترجّع أي حد تاني لشاشته
  RequireAuth     ← صفحات للداخلين بدون قائمة، زي تجهيز الصيدلية
  صفحات عامة      ← الدخول، طلب الانضمام، التفعيل، نسيت كلمة المرور
```

`DashboardEntry`: المديرة بتشوف قائمة البداية مكان لوحة التحكم لحد ما تخلصها أو تخفيها.

`AppLayout` بيجيب المستخدم الحالي. لو السيرفر قال إنه مش داخل، بيحوله لشاشة الدخول. ووقت التحميل بيعرض شكل التطبيق كامل رمادي.

على الشاشات الصغيرة القائمة الجانبية بتختفي، وبتنفتح من زر القائمة بالشريط العلوي كنافذة جانبية من جهة البداية.
