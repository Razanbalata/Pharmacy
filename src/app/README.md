# طبقة التطبيق

هون التطبيق بيشتغل: كل شي بيلف كل الصفحات.

| المكان       | شو فيه                                |
| ------------ | ------------------------------------- |
| `App.tsx`    | نقطة البداية، بتجمع المزودات والتوجيه |
| `providers/` | المزودات: الاستعلامات، اللغة، المظهر  |
| `router/`    | كل الروابط وأي صفحة بتفتح لكل رابط    |
| `styles/`    | الأنماط العامة وألوان نظام التصميم    |

ما في كود صيدلية هون. لو لقيتي حالك بتكتبي منطق بيع أو مخزون بهالطبقة، مكانه غلط.
