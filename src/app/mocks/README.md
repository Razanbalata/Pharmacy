# السيرفر الوهمي

لحد ما نخلص الفرونت، ما في باك إند حقيقي. بداله في سيرفر وهمي بيشتغل جوا المتصفح: بيمسك الطلبات قبل ما تطلع، وبيرد ببيانات شبه بيانات التصميم. الأداة اسمها:

Mock Service Worker

الكود نفسه ما بيعرف إنه السيرفر وهمي. لما يصير الباك إند جاهز، بنطفي الوهمي من ملف البيئة وبس، وما بنغير سطر بالكود.

| الملف         | شو فيه                                                |
| ------------- | ----------------------------------------------------- |
| `fixtures.ts` | البيانات الوهمية، بنفس الأسماء والأرقام اللي بالتصميم |
| `handlers/`   | ملف لكل وحدة، فيه الروابط الوهمية تبعتها              |
| `browser.ts`  | بيشغل السيرفر الوهمي بالمتصفح                         |
| `api-url.ts`  | بيبني العنوان الكامل للرابط                           |

## تجربة الأدوار

من أدوات المطور بالمتصفح بتقدري تغيري المستخدم الوهمي، وبعدين بتعملي تحديث للصفحة:

```js
localStorage.mockRole = 'cashier'
```

القيم: `manager` أو `pharmacist` أو `cashier`.

## القاعدة

كل رابط بنضيفه هون لازم ينضاف لملف العقد كمان، عشان آخر المشروع تكون القائمة كاملة للباك إند:

```
BACKEND_CONTRACT.md
```

السيرفر الوهمي بيشتغل بالتطوير والاختبارات بس، وما بيدخل بالنسخة النهائية أبداً.
