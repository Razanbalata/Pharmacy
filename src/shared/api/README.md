# الاتصال بالسيرفر

| الملف             | شو فيه                               |
| ----------------- | ------------------------------------ |
| `http.ts`         | دالة الطلبات الوحيدة بالمشروع        |
| `errors.ts`       | شكل الخطأ الموحد                     |
| `query-client.ts` | إعدادات جلب البيانات وإعادة المحاولة |

## كيف الدخول شغال

الباك إند لارافيل، والدخول بالكوكيز مش بالتوكن. يعني الجلسة محفوظة بكوكي ما بيقدر الجافاسكربت يقراه، وهاد أأمن. الطريقة اسمها:

Laravel Sanctum SPA

قبل الدخول لازم ننادي هالدالة مرة وحدة عشان السيرفر يحط كوكي الحماية:

```
fetchCsrfCookie()
```

## الأخطاء

أي طلب بيفشل بيرجع خطأ واحد بنفس الشكل، وفيه أسئلة جاهزة:

| السؤال              | معناه                                                 |
| ------------------- | ----------------------------------------------------- |
| `isUnauthenticated` | مش داخل، أو الجلسة خلصت. بنرجعه لشاشة الدخول          |
| `isForbidden`       | داخل بس دوره ما بيسمح                                 |
| `isValidation`      | في غلط بالنموذج، وتفاصيله بـ `fieldErrors` حسب كل حقل |
| `isNetwork`         | الطلب ما وصل السيرفر أصلاً، غالباً النت مقطوع           |

## القاعدة

ما حدا بيستخدم الجلب المباشر من المتصفح بأي مكان تاني. كل طلب بيمر من هون، عشان الكوكيز والحماية والأخطاء يضلوا موحدين.
