# المكونات الأساسية

كل مكون بمجلد لحاله، وبيطلع من ملف واحد:

```
index.ts
```

| المكون    | متى بنستخدمه                                                   |
| --------- | -------------------------------------------------------------- |
| `button/` | أي زر. أنواعه: أساسي، ثانوي، نصي، حذف. زر أساسي واحد بكل شاشة  |
| `badge/`  | شارة الحالة: متوفر، ناقص، منتهي... الحالة بالكلمة مش باللون بس |

المكون الجاي حسب مكتبة المكونات بالتصميم: الجدول.

الألوان دايماً من نظام التصميم، مثلاً:

```
bg-brand  text-ink  border-border
```

ممنوع نكتب لون مباشر زي رقم لون بالكود.

## الحقول

أي حقل بالنموذج بيمر من `Field`. هو اللي بيربط التسمية بالحقل، وبيقرأ الملاحظة أو الخطأ مع الحقل لقارئ الشاشة، وبيعلّم الحقل غلط لما يكون في خطأ:

```tsx
<Field label="اسم الصنف" hint="بالعربي أو الإنجليزي" error={errors.name}>
  {(control) => <Input {...control} value={name} onChange={...} />}
</Field>
```

الحقل مطلوب افتراضياً. اللي مش مطلوب بنعلّمه بـ `optional`.

## الاختيار بالبحث

قاعدة من التصميم: أي قائمة اختيار فيها أكتر من 7 خيارات ما بتكون قائمة عادية، بتكون اختيار بالبحث. البحث فيه بيفهم العربي زي ما الناس بتكتبه، وبيقبل كلمات إضافية زي الاسم الإنجليزي:

```tsx
<Field label="التصنيف">
  {(control) => (
    <Combobox
      {...control}
      options={categories}
      value={categoryId}
      onChange={setCategoryId}
      onCreate={(name) => createCategory(name)}
    />
  )}
</Field>
```

لو ما بدك زر الإضافة، لا تمرري `onCreate`.

بيشتغل كامل بالكيبورد: الأسهم للتنقل، والإدخال للاختيار، والهروب للإغلاق.

## النوافذ

| المكون          | متى                                                                                                             |
| --------------- | --------------------------------------------------------------------------------------------------------------- |
| `Drawer`        | إضافة أو تعديل سريع: زبون جديد، موظف جديد، مرتجع. بتطلع من جهة نهاية الصفحة: الشمال بالعربي، واليمين بالإنجليزي |
| `Dialog`        | قرار قصير بس                                                                                                    |
| `ConfirmDialog` | قبل أي إشي مهم. الرسالة بتقول شو رح يصير بالضبط، مش "متأكد؟"                                                    |

كلهم مبنيين على عنصر النافذة الأصلي بالمتصفح، فالمتصفح هو اللي بيحبس التركيز جواها، وبيسكرها بزر الهروب، وبيرجع التركيز للزر اللي فتحها.

## الرسائل السريعة

بتنادي عليها من أي مكان، بدون ما تحطي مكون بالصفحة:

```ts
toast.success('انحفظت الفاتورة INV-000245', { label: 'اطبعي', onClick: print })
toast.error('ما انحفظ. جربي كمان مرة.')
```

بتختفي لحالها بعد 5 ثواني، وما بيطلع أكتر من 3 مع بعض.
