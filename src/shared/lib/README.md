# أدوات مشتركة

| المكان           | شو فيه                                                             |
| ---------------- | ------------------------------------------------------------------ |
| `cn/`            | بيجمع أسماء الأنماط، والأخير بيغلب. بيعرف أحجام خطوط نظام التصميم  |
| `theme/`         | حفظ المظهر المختار وتطبيقه                                         |
| `arabic-search/` | تطبيع النص العربي للبحث                                            |
| `date/`          | حساب الأيام والأشهر لتاريخ معين، وكتابة الانتهاء زي العلبة 09/2027 |
| `money/`         | كتابة السعر بخانتين عشريتين، والتقريب للأغورة                      |
| `barcode/`       | باركود EAN-13: رقم التحقق، والخطوط للطباعة، والرمز الداخلي         |
| `offline/`       | الشغل بدون نت: حالة الاتصال وصندوق الصادر. إله ملف شرح خاص         |

## البحث العربي

الناس بتكتب "اموكسيل" بدون همزة، و"صيدليه" بالهاء. عشان هيك أي بحث بالنظام لازم يمر على الدالة:

```
normalizeArabic
```

هي بتوحد الألف بكل أشكالها، والتاء المربوطة مع الهاء، والألف المقصورة مع الياء، وبتشيل التشكيل والتطويل، وبتحول الأرقام العربية لأرقام عادية.

ولما بدك تفحصي إذا نص بيطابق كلمات البحث بأي ترتيب، استخدمي:

```
matchesSearch
```
