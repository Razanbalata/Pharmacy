# الشغل بدون إنترنت

القرار: الهيكلية جاهزة هلأ، والتكملة بعد ما يخلص المشروع.

## شو جاهز

| الملف                 | شو بيعمل                                                                  |
| --------------------- | ------------------------------------------------------------------------- |
| `online-status.ts`    | بيعرف إذا في نت أو لا                                                     |
| `outbox.ts`           | صندوق الصادر: العمليات اللي انعملت والنت مقطوع، وبتنبعت بالترتيب لما يرجع |
| `use-outbox-count.ts` | عدد العمليات اللي بتستنى                                                  |

وشريط "الاتصال مقطوع" موجود هون:

```
src/widgets/network-status/
```

## قواعد الصندوق

1. كل عملية إلها رقم بيعمله المتصفح. السيرفر لازم يرفض نفس الرقم مرتين، عشان الفاتورة ما تتسجل مرتين لو انبعتت مرتين.
2. العمليات بتنبعت من الأقدم للأحدث.
3. لو النت لسا مقطوع، بنوقف وبنجرب بعدين.
4. لو السيرفر رفض العملية (مثلاً الكمية خلصت)، بتتعلم إنها فاشلة وبتحتاج حد يشوفها، وبنكمل الباقي.
5. ما في إرسالين بنفس الوقت.

## شو ضايل

- تخزين الصندوق بقاعدة بيانات المتصفح بدل الذاكرة، عشان ما يضيع لو انسكرت الصفحة. التبديل بسطر واحد بملف:

  ```
  index.ts
  ```

- حفظ ملفات التطبيق نفسه بالمتصفح، عشان يفتح بدون نت.
- نسخة محلية من الأصناف والأسعار عشان البحث يشتغل بدون نت.
- الإرسال التلقائي لما يرجع النت.
- شاشة للعمليات الفاشلة.
- بالباك إند: استقبال رقم العملية ورفض التكرار.
