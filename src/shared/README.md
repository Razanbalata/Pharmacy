# الطبقة المشتركة

أدوات عامة بتنفع بأي مشروع، وما إلها علاقة بالصيدلية.

| المكان    | شو فيه                                                               |
| --------- | -------------------------------------------------------------------- |
| `api/`    | الاتصال بالسيرفر، وشكل الخطأ الموحد، وإعدادات جلب البيانات           |
| `config/` | الإعدادات من ملف البيئة، وكل عناوين التطبيق                          |
| `i18n/`   | الترجمة: النصوص بالعربي والإنجليزي، واتجاه كل لغة                    |
| `lib/`    | أدوات صغيرة: البحث العربي، المظهر، التواريخ، الشغل بدون نت           |
| `ui/`     | المكونات الأساسية: زر، حقل، اختيار بالبحث، جدول، نوافذ، رسائل، تحميل |

هالطبقة ما بتستورد من أي طبقة تانية.
