# الطبقة المشتركة

أدوات عامة بتنفع بأي مشروع، وما إلها علاقة بالصيدلية.

| المكان    | شو فيه                                                        |
| --------- | ------------------------------------------------------------- |
| `api/`    | الاتصال بالسيرفر وإعدادات الاستعلامات                         |
| `config/` | قراءة الإعدادات من ملف البيئة                                 |
| `i18n/`   | الترجمة والاتجاه                                              |
| `lib/`    | أدوات صغيرة: تطبيع البحث العربي، تنسيق الأرقام، الشغل بدون نت |
| `ui/`     | المكونات الأساسية: زر، شارة، حقل، وغيرهم                      |

هالطبقة ما بتستورد من أي طبقة تانية.
