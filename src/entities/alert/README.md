# كيان: التنبيهات

هلأ فيه بس عدد التنبيهات الجديدة اللي بيطلع على الجرس وبالقائمة الجانبية. باقي التنبيهات (النقص، الصلاحية، الديون...) بتنبنى بوحدة لوحة التحكم والتنبيهات.

| الملف            | شو فيه                                    |
| ---------------- | ----------------------------------------- |
| `model/types.ts` | شكل ملخص التنبيهات                        |
| `api/queries.ts` | `useAlertSummary`، وبيتحدث لحاله كل دقيقة |
