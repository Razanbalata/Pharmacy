# كيان: الجلسة

مين داخل هلأ، شو دوره، ولأي صيدلية تابع.

| الملف                  | شو فيه                                                                      |
| ---------------------- | --------------------------------------------------------------------------- |
| `model/types.ts`       | شكل المستخدم والصيدلية والأدوار التلاتة                                     |
| `model/navigation.ts`  | عناصر القائمة الجانبية ومجموعاتها، و`navigationFor` بترجع القائمة لدور معين |
| `model/permissions.ts` | مين بيقدر يفتح شو. القائمة الجانبية والروابط والأزرار كلها بتسأل هون        |
| `api/session-api.ts`   | طلب المستخدم الحالي من السيرفر                                              |
| `api/queries.ts`       | الخطاف اللي بتستخدمه الشاشات: `useCurrentUser`                              |

## الصلاحيات

الواجهة بتخبي اللي المستخدم مش مسموحله فيه، بس السيرفر لازم يفحص كمان. الإخفاء بالواجهة للراحة، مش للحماية.

| الدور   | شو ممنوع عليه                                                  |
| ------- | -------------------------------------------------------------- |
| المدير  | ولا شي                                                         |
| الصيدلي | الورديات والمصاريف، الموظفين، الإعدادات                        |
| الكاشير | كل شي غير البيع والفواتير والمرتجعات والزبائن والأصناف للقراءة |
