# طبقة الكيانات

الأشياء الأساسية بالصيدلية. كل كيان إله: شكل بياناته، وطريقة جلبه من السيرفر، وطريقة عرضه البسيطة.

| الكيان            | شو فيه                                                                                                                   |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `session/`        | المستخدم الحالي ودوره وصيدليته، والدخول والخروج واسترجاع كلمة المرور، ومين مسموحله يفتح شو، ووين بيروح كل دور بعد الدخول |
| `join-request/`   | طلب الانضمام والتفعيل، وقرارات صاحبة المنصة                                                                              |
| `pharmacy/`       | بيانات الصيدلية، والإعدادات، والمدن، وقائمة البداية                                                                      |
| `alert/`          | عدد التنبيهات الجديدة                                                                                                    |
| `staff-member/`   | الموظف ودوره وصلاحياته، وجلب القائمة والإضافة والتعديل والإيقاف، ونافذة كلمة المرور المؤقتة                              |
| `product/`        | الصنف ووحدات بيعه ودفعاته وحركاته، وحالته بالمخزون، وشارة الحالة وتاريخ الانتهاء                                         |
| `category/`       | التصنيف باسمه العربي والإنجليزي، وعدد أصنافه                                                                             |
| `ingredient/`     | المادة الفعالة، ومنها النظام بيعرف البدائل                                                                               |
| `supplier/`       | المورد ورصيده وكشف حسابه ودفعاته                                                                                         |
| `purchase-order/` | طلب الشراء وأسطره وحالته وحالة دفعه، والطلبيات المقترحة، والاستلام                                                       |
| `stock-movement/` | سطر بسجل حركات المخزون، وفلاتره ومجاميعه                                                                                 |
| `damage-record/`  | سجل التالف وأسبابه، وملخص الشهر، والمنتهي اللي لسا بالمخزون                                                              |
| `stock-count/`    | الجرد وأسطره وأسباب الفروقات                                                                                             |
| `cart/`           | الفاتورة اللي عم تنباع هلأ: الأسطر والوحدات والمجاميع                                                                    |
| `customer/`       | الزبون وحسابه: الدين محسوب من الحركات، عمر الدين، كشف الحساب، التسديد                                                    |
| `shift/`          | الوردية وملخص نقدها، وسجل الورديات بالمبيعات والمتوقع والفعلي والفرق                                                     |
| `expense/`        | مصاريف الصيدلية: أنواعها، من الدرج أو من برا، والشهري منها                                                               |
| `invoice/`        | فاتورة البيع، والبيع نفسه، والفواتير المعلقة                                                                             |
| `sale-return/`    | المرتجع وأسبابه                                                                                                          |
| `activity/`       | سطر بسجل النشاط: مين، متى، شو نوعه، والفلاتر                                                                             |

الكيانات الجاية:

- الفاتورة والمرتجع
- الزبون
- الوردية
